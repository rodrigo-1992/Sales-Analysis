### Sobre o Projeto

Este projeto de portfólio foi desenvolvido como parte do meu plano de estudos para me tornar um Analista de Dados, aplicando na prática os conceitos e ferramentas que considero essenciais para o mercado em 2026/2027. 
A análise explora feita em Sales Analysis tem o objetivo de responder a perguntas de negócio e gerar insights acionáveis.

A motivação por trás deste trabalho é demonstrar minha capacidade de atuar como um Analista de dados, indo além da construção de relatórios para criar um pipeline de dados completo, desde a extração e limpeza até a visualização e storytelling, preparado para os desafios do futuro da análise de dados.

### Funcionalidades

- **Pipeline de Dados (ETL):** Extração, limpeza e transformação de dados utilizando Python (pandas) para garantir a qualidade e confiabilidade da análise.
- **Análise Estatística:** Aplicação de conceitos de estatística descritiva e testes de hipóteses para validar padrões e tendências identificadas.
- **Dashboard Interativo:** Criação de visualizações dinâmicas com [**Power BI** ou **Tableau**] para explorar os dados de forma intuitiva.
- **Storytelling com Dados:** Estruturação da análise em uma narrativa clara, respondendo perguntas de negócio e sugerindo recomendações práticas.
- **Automação e Eficiência:** Utilização de SQL para consultas complexas e funções de janela, demonstrando capacidade de manipulação eficiente de grandes volumes de dados.

### Tecnologias Utilizadas

- **Linguagem de Programação e Bibliotecas:**
    - **Python:** Core da análise de dados.
    - **Pandas:** Manipulação e limpeza de dados.
    - **Matplotlib / Seaborn:** Visualização de dados exploratória.
- **Linguagem de Consulta:**
    - **SQL:** Consultas, agregações, CTEs e funções de janela.
- **Ferramentas de Visualização e BI:**
    - **Power BI:** Criação de dashboards e relatórios interativos.
- **Controle de Versão e Colaboração:**
    - **Git e GitHub:** Versionamento do código, do pipeline e da documentação.
- **Ambiente de Desenvolvimento:**
    - **Jupyter Notebook:** Ambiente interativo para exploração e análise dos dados.
- **Ferramentas de Produtividade:**
    - **Gemini Code Assist / Microsoft Copilot:** Utilizados como assistentes para otimizar a escrita de código e a geração de insights (com revisão crítica).

### Pré-requisitos

Para rodar este projeto e reproduzir a análise em sua máquina, você precisará ter instalado:

- **Git:** Para clonar o repositório.
- **Python 3.8 ou superior:** Para executar os scripts e notebooks.
- **Gerenciador de Pacotes pip:** Para instalar as dependências do projeto.
- **(Opcional) Power BI Desktop ou Tableau Public:** Para visualizar os dashboards interativos.
- **Acesso a um Banco de Dados (ex: PostgreSQL, MySQL) ou ferramenta de SQL:** Caso queira testar as consultas diretamente.

### Instalação e Execução

Siga os passos abaixo para configurar e executar o projeto em sua máquina local.

```bash
# 1. Clone este repositório
git clone https://github.com/rodrigo-1992/Sales-Analysis.git

# 2. Acesse a pasta do projeto no terminal/cmd
cd Sales-Analysis

# 3. Instale as dependências do Python (listadas no arquivo requirements.txt)
pip install -r requirements.txt

# 4. Execute o Jupyter Notebook para explorar a análise
jupyter notebook

# Ou, se preferir executar um script Python diretamente:
# python nome_do_script.py

**Notas adicionais:**
- Certifique-se de estar no diretório correto do projeto antes de rodar os comandos.
- Para o dashboard, abra o arquivo `dashboard.pbix` (Power BI).
